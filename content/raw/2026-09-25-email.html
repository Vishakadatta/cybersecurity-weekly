⚠ BREAKING CVE-2026-94127

Critical F5 BIG‑IP APM OAuth Server Zero‑Day (CVE‑2026‑94127) Actively Exploited for Unauthenticated RCE

A heap‑based buffer overflow in F5 BIG‑IP Access Policy Manager when used as an OAuth authorization server (CVE‑2026‑94127) enables unauthenticated remote code execution. F5 released engineering hotfixes on September 22; CISA added the flaw to its KEV catalog and mandated remediation by September 25 for federal agencies.

📈 Impact: Attackers can send crafted OAuth traffic to the vulnerable virtual server and gain code execution without any authentication, bypassing traditional management‑interface restrictions. All BIG‑IP deployments running APM as an OAuth authorization server are at immediate risk.

✅ Action: Apply the appropriate F5 engineering hotfix for your BIG‑IP version immediately and restrict external access to any virtual server hosting the APM OAuth authorization profile.

⚠ BREAKING CVE-2026-87902

Critical WordPress RCE (CVE‑2026‑87902) Exploited Within Hours of Disclosure

WordPress’s get_page_template() function contains a critical RCE flaw (CVE‑2026‑87902, CVSS 9.2) that lets an unauthenticated attacker include any readable local PHP file when a theme’s top‑level directory starts with “page‑”. Within hours of disclosure, threat actors launched at least 68 exploitation attempts from the United States and Indonesia, targeting /usr/local/lib/php/pearcmd.php and uploading a GitHub‑hosted web shell.

📈 Impact: Security teams must assume active exploitation in the wild and recognize that successful attacks require specific theme naming and file‑read permissions, which many sites inadvertently meet.

✅ Action: Apply the WordPress 6.5.4 (or later) patch immediately and backport fixes to all supported branches back to 4.7, then audit themes for “page‑” directories and remove or restrict access to readable PHP files.
