⚠ BREAKING CVE-2026-76460

Cisco Issues CVE‑2026‑76460 Zero‑Day, CVSS 10.0, Actively Exploited in ISE API Authentication Bypass

Cisco disclosed a critical authentication‑bypass zero‑day (CVE‑2026‑76460) in its Identity Services Engine (ISE) and ISE Passive Identity Connector. The flaw allows an unauthenticated remote attacker to bypass the web‑based management interface via an unprotected API endpoint, gaining root‑level command execution. Active exploitation has been confirmed.

📈 Impact: Security teams using Cisco ISE risk unauthorized network access and full device compromise, potentially exposing the entire enterprise LAN/WAN to malicious actors.

✅ Action: Immediately upgrade all ISE and ISE‑PIC nodes to the latest patched releases and audit access.log for the “dummyuser” indicator, re‑imaging any compromised devices.

⚠ BREAKING

Critical Check Point Management Server Stack Overflow Allows Unauthenticated Remote Code Execution as Root

A stack‑based buffer overflow in the login routine of Check Point Security Management Server and Log Server (CVE‑2026‑91843) lets unauthenticated attackers send an overlong username and execute arbitrary code with root privileges over the network. Check Point rates the flaw 9.8 CVSS and has issued a LivePatch fix.

📈 Impact: Security teams face immediate risk of full system compromise on any vulnerable management or log server, regardless of configuration or VPN usage.

✅ Action: Apply the Check Point LivePatch update (advisory SK1000155) and, if patching cannot be done immediately, restrict access to trusted IPs via the SmartConsole Trusted Clients setting.

🎯 FOCUS CVE-2026-77179

Critical Docker Sandboxes Flaw (CVE‑2026‑77179) Allows Guest Code to Escape macOS Host Filesystem

Docker Sandboxes versions 0.28.0‑0.41.x on macOS contain a critical vulnerability (CVE‑2026‑77179) that lets malicious code inside a sandbox VM follow symlinks via virtio‑fs, escape the shared project directory, and read or modify any host file with the host account’s privileges.

📈 Impact: Security teams must treat any Docker Sandboxes deployment on macOS prior to 0.42.0 as compromised if malicious code runs inside the sandbox, because an attacker can gain full host file system access and potentially execute code as the host user.

✅ Action: Upgrade Docker Sandboxes to version 0.42.0 or later immediately and audit host systems for unauthorized file changes.
