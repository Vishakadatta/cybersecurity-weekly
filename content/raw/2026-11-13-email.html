Apache mod_http2 RCE Under Active Attack, OpenSSH 'sshole' Exploited, and Microsoft's Record Patch Tuesday

This week presents an aggressive barrage of infrastructure threats led by active in-the-wild exploitation of Apache's HTTP/2 engine and OpenSSH authentication on musl-based distributions. Simultaneously, Microsoft released a massive Patch Tuesday addressing actively targeted zero-days, while high-impact supply-chain attacks struck Red Hat Quay and thousands of GitHub CI/CD workflows. Security teams should immediately triage internet-facing endpoints, rotate exposed automation tokens, and apply pending hypervisor and runtime fixes.

⚠ BREAKING CVE-2026-106023 CVE-2026-42356

Critical Remote Code Execution Flaw in Apache HTTP Server’s HTTP/2 Module Patched

Apache HTTP Server 2.4.55‑2.4.70 with mod_http2 enabled contains a critical unauthenticated RCE vulnerability (CVE‑2026‑119618) that is actively exploited; the issue is fixed in Apache 2.4.71 and corresponding distro packages.

📈 Impact: Unauthenticated attackers can execute arbitrary code on vulnerable web servers, potentially taking full control of the server process. Exploits work against default configurations with HTTP/2 enabled, posing immediate risk to internet‑facing services.

✅ Action: Upgrade to Apache HTTP Server 2.4.71 or apply the vendor‑specific patches (e.g., mod_http2‑2.0.26‑7.el9_9.1 for RHEL) and disable HTTP/2 if you cannot patch immediately.

Microsoft November 2026 Patch Tuesday Fixes Over 1,250 Flaws, Including Actively Exploited Outlook Zero‑Day

Microsoft released November Patch Tuesday addressing 1,259‑1,260 CVEs across Windows, Office, Edge, Exchange, SharePoint, LDAP, AD DS, Hyper‑V and .NET, with 68 critical bugs. A spoofing zero‑day in Outlook (CVE‑2026‑124194) is already being exploited to steal NTLMv2 hashes, and multiple remote‑code‑execution flaws affect LDAP, AD DS and Hyper‑V.

📈 Impact: Security teams face immediate risk of credential theft and domain‑wide compromise if the Outlook zero‑day or the LDAP/AD DS RCE bugs are not patched, while unpatched privilege‑escalation flaws in Hyper‑V and Edge could enable attacker persistence and lateral movement.

✅ Action: Deploy the November updates across all Windows, Office, Edge, Exchange, SharePoint, LDAP, AD DS and Hyper‑V endpoints without delay.

⚠ BREAKING 🔐 GT10

Active Exploitation of OpenSSH “sshole” Flaw Grants Unauthenticated Remote Access

The newly disclosed sshole vulnerability in OpenSSH, triggered by a musl library interaction, is being actively exploited to bypass authentication and obtain privileged SSH access on vulnerable Linux devices, with attacks observed in Southeast Asian honeypots.

📈 Impact: Security teams must assume that any Linux host running OpenSSH with musl is at immediate risk of remote compromise and that attackers are already deploying a backdoor called TAC Agent for persistence.

✅ Action: Deploy the OpenSSH patch released today and verify that musl‑linked binaries are updated or replaced on all affected systems.

🎯 FOCUS CVE-2026-111760

Git Fixes Critical Integer Truncation Vulnerability (CVE‑2026‑111760) in 2.56.1 and Back‑ported Releases

Git’s integer truncation flaw (CVE‑2026‑111760) allowed malicious repositories to execute attacker‑controlled code during recursive clones and submodule fetches. The vulnerability is patched in Git 2.56.1 and back‑ported to 2.50.2, 2.51.3, 2.52.1, 2.53.1, 2.54.1, and 2.55.1. Immediate upgrade is required.

📈 Impact: Security teams must treat any Git clone operation as potentially hostile, especially when pulling untrusted repositories or using recursive submodule fetches, because the flaw could inject malicious hooks via crafted path names.

✅ Action: Upgrade all Git installations to 2.56.1 or the appropriate back‑ported version and enforce trusted‑source cloning policies.
