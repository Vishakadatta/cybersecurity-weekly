⚠ BREAKING CVE-2026-102255

SonicWall Issues Hotfix for Critical CVE‑2026‑102255 SSRF in SMA1000 Appliances as Exploits Appear in the Wild

SonicWall released patches for four critical flaws in SMA1000 gateways, with CVE‑2026‑102255—a pre‑authentication SSRF in the WorkPlace portal—rated 10.0 CVSS. Within days of release, threat‑monitoring honeypots observed exploitation attempts targeting internal CouchDB services, confirming active abuse of the vulnerability.

📈 Impact: Unauthenticated attackers can force the appliance to issue internal requests, potentially accessing sensitive services and executing unauthorized operations on any exposed SMA1000 device.

✅ Action: Apply the SonicWall hotfix (12.4.3‑03670 or later, 12.5.0‑03082 or later) immediately and verify the appliance restarts successfully.

⚠ BREAKING CVE-2026-96940

Microsoft Issues Out‑of‑Band Patch for Critical Exchange Server Privilege‑Escalation Flaw (CVE‑2026‑96940)

Microsoft released an out‑of‑band update for CVE‑2026‑96940, a high‑severity Exchange Server vulnerability that lets authenticated attackers elevate privileges and read other users' mailboxes within the same organization. The flaw is actively exploited, carries an 8.8 CVSS score, and affects multiple on‑premises Exchange versions.

📈 Impact: Security teams must assume that any compromised credential could be used to harvest internal email traffic, exposing sensitive communications and attachments. The vulnerability does not cross tenant boundaries but can compromise every mailbox on an affected server.

✅ Action: Apply the October 2, 2026 Exchange Server security updates immediately to all affected on‑premises installations.

⚠ BREAKING

Cisco Issues Critical NX‑OS Advisories for Five Root‑Level Exploits

Cisco disclosed five critical vulnerabilities in NX‑OS that allow remote code execution with root privileges on Nexus 3000 and Nexus 9000 switches. Exploits target NX‑API, Next‑Generation OAM, and MPLS OAM when those features are enabled, potentially enabling full device takeover or denial‑of‑service.

📈 Impact: Compromised switches can give attackers unrestricted control over data‑center traffic, manipulate VLANs, or disrupt services, exposing the entire fabric to breach or outage.
