⚠ BREAKING CVE-2026-104286

Critical FortiMail Zero‑Day (CVE‑2026‑104286) Actively Exploited for Unauthenticated File Writes

CISA added Fortinet FortiMail CVE‑2026‑104286 to its KEV catalog after confirming active exploitation. The unauthenticated path‑traversal flaw (CVSS 9.8) lets attackers write arbitrary files via crafted HTTP/HTTPS requests, enabling remote code execution on FortiMail 8.0.0‑8.0.1, 7.6.0‑7.6.6, 7.4.0‑7.4.8, and 7.2.0‑7.2.9.

📈 Impact: Security teams must assume that any vulnerable FortiMail deployment could be compromised, with attackers able to plant malicious binaries and gain system control.

✅ Action: Apply the upcoming FortiMail 8.0.2, 7.6.7, or 7.4.9 patches immediately, or mitigate by disabling IBE support and restricting management‑interface access.

⚠ BREAKING CVE-2026-88771 CVE-2026-88772

Critical RCE Zero-Days Exploited in Citrix NetScaler ADC and Gateway

Threat actors are actively exploiting two critical pre-authentication RCE vulnerabilities, CVE-2026-88771 and CVE-2026-88772, in Citrix NetScaler ADC and Gateway. Attackers use these flaws to bypass authentication, achieve root-level access, and deploy sophisticated web shells like WHIPSHOT and Python-based tunnelers like SLAPSHOT to establish persistence and conduct internal network reconnaissance.

📈 Impact: These vulnerabilities provide attackers with a skeleton key to enterprise networks, allowing for full system compromise, credential theft, and lateral movement. Post-exploitation activity includes the staging of configuration data and the use of obfuscated C2 payloads.

✅ Action: Immediately apply the latest security patches provided by Citrix and perform a thorough forensic sweep for indicators of compromise, as patching alone does not remove existing unauthorized access.

⚠ BREAKING CVE-2026-86950

Apple CoreGraphics Zero‑Day (CVE‑2026‑86950) Exploited in Targeted Attacks – Emergency Patches Issued

Apple patched CVE‑2026‑86950, an out‑of‑bounds write in CoreGraphics that allows arbitrary code execution via malicious PDFs. The flaw was weaponized in sophisticated attacks against specific individuals on iOS versions prior to iOS 27, prompting CISA to add it to the KEV catalog and mandate federal remediation by Oct 2.

📈 Impact: Security teams must treat this as a high‑severity, actively exploited vulnerability affecting a wide range of iPhone, iPad, and macOS devices and prioritize patching to prevent remote code execution via crafted PDF files.

✅ Action: Deploy Apple’s emergency updates for iOS 26.7.1, iPadOS 26.7.1, macOS Tahoe 26.7.1 and macOS Sequoia 15.8.1 immediately and verify that all devices are no longer on vulnerable branches.

⚠ BREAKING CVE-2026-73570

Critical Zimbra RCE Exploited via Malicious SMTP Requests

Threat actors are weaponizing CVE-2026-73570, a critical OS command injection flaw in Zimbra Collaboration Suite, to deploy web shells and exfiltrate mailbox data. Exploitation requires no authentication, triggered by specially crafted SMTP requests on servers with the optional zimbra-snmp package enabled. Attackers perform remote code execution to establish persistence, escalate privileges, and harvest sensitive authentication credentials.

📈 Impact: Successful exploitation grants attackers full remote control over mail servers, enabling complete access to organizational email data and internal credentials. The widespread nature of this campaign poses a severe risk of data breach and persistent unauthorized network access.

✅ Action: Ensure all Zimbra Collaboration Suite instances are updated to version 10.1.20 or later and audit /var/log/zimbra.log for suspicious service restarts or unauthorized files in webapps directories.
