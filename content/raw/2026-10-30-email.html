⚠ BREAKING CVE-2026-97229

CISA Adds Critical GitLab RCE Flaw to KEV After Active Exploitation

CISA placed CVE-2026-97229, a CVSS 10.0 integer overflow in GitLab CE/EE that enables unauthenticated remote code execution via crafted CI/CD regular expressions, on its Known Exploited Vulnerabilities catalog. The flaw was actively probed on Alpine Linux’s GitLab instance, causing worker crashes and near‑successful exploitation attempts.

📈 Impact: Security teams must treat this GitLab vulnerability as an immediate, high‑severity threat that can compromise any self‑hosted GitLab server lacking the required Ruby runtime patches.

✅ Action: Patch GitLab to version 19.4.2, 19.3.5, or 19.2.8 and upgrade the Ruby runtime to 3.3.13, 3.4.12, 4.0.9 or later.

⚠ BREAKING 🔐 TraderTraitor (Lazarus Group / APT38)

North Korean Hackers Steal $6.3 Billion from Binance via Compromised DevOps Laptop

North Korean state-sponsored threat group TraderTraitor breached Binance and drained roughly $6.3 billion across ten blockchains. Attackers compromised a DevOps engineer's endpoint to gain access to a service container, submitting unauthorized withdrawal transactions without leaking private keys. Stablecoin issuers and decentralized protocols have frozen nearly $3 billion of the illicit transfers.

📈 Impact: The breach highlights how administrative endpoint compromise can bypass hot-wallet isolation and directly interact with backend transaction services. Organizations face extreme blast radiuses when infrastructure controls fail to separate developer access from high-value execution containers.

✅ Action: Enforce strict zero-trust boundaries and multi-party authorization workflows for high-privilege service containers, ensuring administrative endpoints cannot directly trigger transaction or withdrawal pipelines.

⚠ BREAKING

WordPress Core Remote Code Execution Flaw Triggers Nearly 63,000 Exploit Attempts Within 24 Hours

A high‑severity remote code execution flaw in WordPress Core (versions 4.7‑7.1.3) was weaponized within seconds of the October 28, 2026 patch release, generating 62,969 blocked attack attempts in a single day. The bug stems from a predictable, web‑accessible staging directory used during full‑package core upgrades, allowing unauthenticated attackers to race the unpacking process and execute arbitrary PHP code.

📈 Impact: Security teams must assume that any site running the affected WordPress versions is actively probed and potentially compromised during upgrade windows.

✅ Action: Apply the October 28 patch immediately, enforce non‑web‑accessible staging paths, and monitor for requests to wp‑content/upgrade and setup‑config.php during updates.

⚠ BREAKING CVE-2026-98432

Critical Linux Kernel TCP Flaw Enables Remote Root Execution via MPTCP

A critical use-after-free race condition in the Linux kernel's TCP implementation, CVE-2026-98432, enables unauthenticated remote attackers to execute code as root against systems with Multipath TCP (MPTCP) listeners. Exposure is widespread because network services built with Go 1.24 or later enable MPTCP sockets by default.

📈 Impact: Unauthenticated remote attackers can gain full root control over servers hosting MPTCP-enabled network services. Exposure extends across major enterprise distributions, including RHEL and Ubuntu installations running Go-based applications.

✅ Action: Upgrade to patched Linux distribution kernels immediately or disable MPTCP on affected hosts until vendor updates are applied.
