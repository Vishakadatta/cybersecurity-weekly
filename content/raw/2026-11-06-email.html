⚠ BREAKING CVE-2026-123158

OpenSSH “*sshole” Flaw Enables Password‑less Logins on Musl‑Based Linux Systems

A critical OpenSSH vulnerability (CVE‑2026‑123158, CVSS 8.1) lets attackers log in to any account whose password field is set to “*” on musl‑based Linux distributions when PAM is disabled, by submitting an oversized password (257‑1024 bytes). The flaw affects Alpine Linux, OpenWrt, Buildroot, Yocto and any OpenSSH 10.6p1 or earlier built without PAM.

📈 Impact: Any reachable SSH service on the affected configurations can be compromised with a single connection, granting the attacker the privileges of the password‑less account, often key‑only or service accounts.

✅ Action: Upgrade OpenSSH to 10.6p2 immediately and disable PasswordAuthentication or enable PAM on all affected hosts.

⚠ BREAKING

Critical APT Vulnerability Allows MITM Package Swaps and Root Code Execution on Debian and Ubuntu

A flaw in APT (CVE-2026-109518) lets a man‑in‑the‑middle replace verified Debian and Ubuntu packages with malicious ones, executing arbitrary code as root when APT retries failed downloads—a default behavior from Debian 12 and Ubuntu 22.04 onward.

📈 Impact: Security teams face the risk of full system compromise during routine package installations if network traffic can be tampered with. The vulnerability affects all current Debian and Ubuntu releases and any derivatives that use APT.

✅ Action: Immediately apply the released APT updates for your distribution and verify that the Acquire::Retries setting is disabled or tightly controlled.

⚠ BREAKING

Critical Xen Hypervisor Flaws Allow Malicious VM to Access Any Guest Memory

Two vulnerabilities (CVE‑2026‑102703, CVE‑2026‑102704) in Xen hypervisor versions 4.6 and later let a compromised guest VM read and write the memory of any other VM, including dom0. The bugs stem from improper permission checks in the grant‑copy operation. Patches are released; no mitigation exists yet.

📈 Impact: A single malicious VM can break isolation and potentially take full control of the host, compromising all workloads and management domains.

✅ Action: Apply the Xen Project XSA‑523 patches immediately to all affected hosts and update dependent platforms such as XCP‑ng, Qubes OS 4.3, and Debian xen packages.

🎯 FOCUS

Critical Ruby on Rails Active Storage ImageMagick Bug Enables Arbitrary File Write and Read

A critical flaw in Rails Active Storage allows unauthenticated attackers to write arbitrary files and read sensitive data by uploading crafted images processed with ImageMagick. The vulnerability scores 9.8 CVSS, is tracked as GHSA-f3w6-w445-fwh9, and is fixed in Rails 8.1.4.

📈 Impact: Security teams must treat any Rails app using Active Storage with ImageMagick as compromised, as attackers can exfiltrate secret_key_base, credentials, and achieve remote code execution.

✅ Action: Upgrade Rails to 8.1.4.1 or 8.0.5.2 immediately and disable ImageMagick processing for untrusted uploads.
